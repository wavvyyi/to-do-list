# to-do-list
CS193 Final Project

# Goal
To create a tool for creating, managing, and viewing user-created tasks.

# Features
Creating tasks with titles and descriptions, editing and deleting tasks, and persistent storage.

# Schedule
The ability to tag tasks and assign deadlines, different view options such as by tag and date, and a custom GUI.

# Tech Stack
Language: Java
Libraries: JST, JavaFX
